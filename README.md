# Operating Systems 2026 – Florea David (FAF-242)

Laboratory works for the Operating Systems course, FCIM / FAF, UTM, 2026-2027.

- `lab3/` – The Command Line: Shell, Pipes and Text Filters
- `lab4/` – The xv6 Shell from the Outside
- `lab5/` – The File System with Your Own Hands (Linux)
- `lab6/` – Inside the xv6 File System
- `lab7/` – Three Small Programs: Processes, Redirection, a Pipe (Linux)
- `lab8/` – The Same Calls, Inside Your Own OS (xv6)

Each lab folder contains the report (`.docx`), the programs/scripts handed in, and everything used to
complete the lab:
- `README.md` – what is in the folder, and an index of all figures;
- `commands.md` – every command, in the order it was run, grouped by part;
- `commands.sh` – (Linux labs 3, 5, 7) re-runs the commands: `bash commands.sh [folder]`;
- `screenshots/` and `outputs/` – every figure of the report, as PNG and as plain text;
- `generated/` – files the lab produced; `variants/` – temporary versions of programs.
